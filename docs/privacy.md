# Zava Securities Municipal Deal Desk - Privacy Statement

Effective date: 1 August 2026

## Scope

This statement describes data processing for the Zava Securities Municipal Deal Desk
technical demonstration. **Zava Securities is fictional**, and the demonstration is
intended to use synthetic municipal securities data only.

This statement does not replace the privacy notices, data policies, product terms or
administrator controls of the organization and Microsoft services through which you
access the application.

## Information processed

Depending on the access surface and administrator configuration, the demonstration can
process:

- prompts, approval decisions and other text you submit;
- generated responses, citations, control findings and workflow status events;
- session, conversation and correlation identifiers;
- Microsoft Entra ID, Teams or Microsoft 365 account identifiers needed to authenticate
  and authorize access;
- service, security, performance, token usage, error and diagnostic telemetry; and
- configuration metadata such as the selected demonstration persona and group claims.

The supplied corpus, issuers, transactions and private pricing records are synthetic.
The application is not designed to collect real customer, investor, issuer, employee,
personal, confidential or material nonpublic information. **Do not submit such data.**

## How information is used

Information is processed to:

- authenticate users and enforce configured access;
- run the requested multi-agent workflow and connected tools;
- produce, cite and review a demonstration answer;
- pause for and record a human approval decision;
- apply safety and modeled conduct controls;
- monitor reliability, latency, usage and errors; and
- investigate technical, security and governance issues.

The demonstration does not sell personal information or use conversation data for
advertising.

## Services and data locations

Processing can occur through Microsoft Teams, Microsoft 365, Azure Bot Service,
Microsoft Foundry, Azure AI Search, Azure Storage, Azure Monitor, Application Insights,
Log Analytics and related Microsoft identity and networking services.

Data location, cross-region processing, retention and subprocessors are governed by the
organization's Microsoft tenant, Azure subscription, Power Platform environment,
service configuration and applicable Microsoft agreements. Historical Copilot Studio or
Microsoft 365 activity, if enabled, can be stored under Microsoft 365 service terms
rather than Azure service terms.

## Retention and access

Conversation, trace, diagnostic and service data can be retained according to the
organization's Microsoft 365, Power Platform, Azure and monitoring retention settings.
Administrators and authorized operators can have access to this information for support,
security, evaluation and governance. Deleting or replacing the demonstration does not
necessarily immediately delete data retained by an underlying service, backup or audit
policy.

## Your choices

- Do not submit sensitive or real-world financial information.
- Stop using the demonstration if you do not agree with this processing.
- Ask the organization administrator who provided access about available access,
  correction, deletion, retention or audit controls.
- Use only approved organizational accounts and devices.

## Security and limitations

The demonstration uses Microsoft Entra authentication and managed identities where
supported, but no system is guaranteed to be completely secure. Report suspected
unauthorized access or disclosure to the organization administrator or session organizer.
Do not post secrets, personal information or confidential data in a public GitHub issue.

## Changes and contact

This statement can be updated as the demonstration or its service configuration changes.
The effective date above identifies the current version. For privacy, access or data
handling questions, contact the organization administrator or session organizer who
provided access. For public technical issues that contain no confidential information,
use the repository's GitHub issue tracker.
